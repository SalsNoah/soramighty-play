ブラウザで遊べる三人麻雀の公開用ファイルです。

## 収録版
v0.25（2026-10-29更新）。続きから再開した後のCPU進行、別タブの保存保護、効果音、宣言と待ちの表示、精算画面、牌の先読みを修正しました。従来の白の和了・立直・河・OG画像・最大配置の修正を維持しています。ゲーム計算・CPU戦略・オンライン処理は変更していません。

## 保存と再開
同じブラウザの自動保存から「続きから」を選べます。CPU自動進行は保存前の明示設定を保持し、新規の既定はONです。意図して止めた場合は卓上の「CPUを再開」で再開できます。別タブが対局中なら先のタブを閉じて再確認してください。セーブを移す場合は「保存・設定」から専用JSONを保存・読み込みできます。

## 効果音と残件
既存の効果音ラボ4素材を短縮・ピッチ調整・フェードして11イベントへ割り当てています。11素材を新しく取得したものではありません。新規の音設定は最初のユーザー操作後にON・50%、保存済みのミュートと音量は保持します。BGMは組み込んでいません。

高解像度牌の原本、CPUの白早切り目標、音の実聴・物理遅延、人による宣言認知、実機で長時間隠したタブの復帰確認は残件です。現行CPUは変更していません。
