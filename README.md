# ソラマイティ

ブラウザで遊べる三人麻雀の公開用ファイルです。

## 収録版
v0.24 D。従来の公開版と同一のゲーム内容を、GitHub Pagesの配信パス向けにbuildしています。

## セーブを移す場合
旧ページの「保存・設定」から対局をJSON保存し、新ページで読み込んでください。ページを閉じる前に保存してください。アイコン写真は移行先で再設定が必要です。

## オンライン対戦
このページは静的配信です。対人オンライン対戦には別途、既存のWindows対戦サーバーが必要です。このリポジトリに対戦サーバー、招待情報、個人データは含まれません。

## 配布内容
ゲーム実行用のHTML・JavaScript・CSS・画像とライセンス表示のみ。開発資料・テスト用局面・ユーザーのプレイデータは含みません。
