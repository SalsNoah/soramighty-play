# ソラ・マイティ 先行公開版

CPU2人と遊ぶ三人麻雀のブラウザ用実行ファイルです。2026-10-31更新。

通常/リーチBGM、指定場面のSE、8種類の演出、アリスの最新牌表示、保存からの復元処理を更新しました。既存の単独白CPU評価とゲーム計算を維持し、一発予告は全体平均方式、牌画像は現行66×90を採用しています。

完成版ではありません。描画33ms基準は未達、自然対局の予告色検証は10条件中9条件が目標範囲内です。実機・人の試聴・長時間背景復帰の確認は残っています。既知の残件を含む先行公開として承認された版です。

タイトルの「この試用版について」から、更新内容・残件・音源出典を別画面で読めます。対局画面に説明帯や追加警告はありません。

## 保存と音声

操作ごとに同じブラウザへ自動保存します。タイトルの「続きから」で再開でき、「保存・設定」からJSONの保存/読込、BGM・SEの個別音量とミュート、演出の強さを設定できます。説明画面は保存を変更せず、音を再生しません。

## 配信範囲

HTML・JavaScript・CSS・必要な画像/フォント/ゲーム音源・権利表示・配信識別情報のみです。開発ソース、私有検証記録、テスト用局面、プレイデータ、音源ZIP/元動画、音源素材集は公開物に含めません。対人オンライン対戦には別途既存の対戦サーバーが必要です。

第三者音源はソフトウェアのMIT等で再許諾しません。AUDIO_NOTICE.txt、THIRD_PARTY_LICENSES.txt、about.htmlを参照してください。
